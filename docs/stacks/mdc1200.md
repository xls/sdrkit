# MDC-1200

The 1200 bit/s signalling bursts on analogue FM voice channels: every FM carrier inside the capture is followed, and the unit id of each burst is listed with the calls.

Stack id: `mdc1200`. Group: Trunking.

## How it works

The stack is the multi-carrier receiver of [Voice channels](voice_channels.md) with no channel plan. A carrier finder searches a raster of 12.5 kHz through the multiples of the step; `raster_step_hz` and `raster_origin_hz` change it. Every carrier is a narrow FM carrier, labelled by its frequency in MHz. The strongest open carrier plays. The table `channels` holds the carriers and the table `calls` the transmissions.

Each carrier has a burst decoder. It takes the voice band of the discriminator, before de-emphasis, of the blocks that pass the squelch gate. A new carrier's receiver is first fed the last 0.25 s of the capture, so a burst at the start of a transmission is not lost.

A burst is 1200 bit/s in tones of 1200 Hz and 1800 Hz. A packet holds an operation code, an argument and a unit id of 16 bits, with a CRC-16 check value. A packet whose check value is wrong is dropped and counted in `check_failures`. A double packet (operation codes 0x35 and 0x55) holds four more bytes, shown in `extra`.

| Operation code | Argument | Meaning shown |
|---|---|---|
| 0x01 | 0x80 | PTT ID (start of transmission) |
| 0x01 | 0x00 | PTT ID (end of transmission) |
| 0x01 | other | PTT ID |
| other | any | the two numbers |

FleetSync bursts are not MDC-1200 bursts: the [FleetSync](fleetsync.md) stack reads them.
