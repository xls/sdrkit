# FSK200/500 and FSK200/1000

200 Bd 2-FSK number senders: F01 (500 Hz shift, ITA2 figure blocks) and F06 (1000 Hz shift, 288-bit blocks under a CRC-16: figure blocks, ASCII, F06a files).

Stack id: `fsk200`. Group: HF utility.

## Tuning

| Property | Value |
|---|---|
| Default frequency | 6.5 MHz |
| Tuning range | Anywhere the radio tunes |
| Sample rate | 2 MHz |
| Smallest sample rate | 250 kHz |
| Signal bandwidth | 4 kHz |
| Offset from the signal | 20 kHz |
| Radio filter | 1.75 MHz |
| Automatic gain | Radio AGC |

| Id | Name | Default frequency |

| `f01` | FSK200/500 (F01) | 6.5 MHz |
| `f06` | FSK200/1000 (F06) | 6.5 MHz |
