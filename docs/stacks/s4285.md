# STANAG 4285

2400 Bd frames of 256 symbols on 1800 Hz, 75 to 3600 bit/s: coded rates found by their start of message; text and STANAG 5066 D_PDUs.

Stack id: `s4285`. Group: HF utility.

STANAG 4285: 2400 Bd frames of 256 symbols (80 sync, 176 scrambled) on 1800 Hz, 75 to 3600 bit/s. The coded rates are found by their start-of-message pattern; an uncoded rate is a setting. ```text iq -> [hf_front 24 kHz] -> [s4285: serial-tone front, frame sync, DFE, a deinterleaver and Viterbi decoder a profile] -> text, D_PDUs, events ```

Standard: NATO STANAG 4285 (not public).

## Description

2400 Bd frames of 256 symbols on 1800 Hz, 75 to 3600 bit/s: coded rates found by their start of message; text and STANAG 5066 D_PDUs. The receiver finds the 80 sync symbols of a frame and confirms them one frame later, trains a decision-feedback equaliser on the sync and the three known blocks of each frame, and runs a deinterleaver and a K = 7 Viterbi decoder for every coded profile; the first whose bits show the start-of-message pattern 03873C3C is read until the end pattern 4B65A5B2. An uncoded profile has no such pattern and must be set. STANAG 4285 is sold, so no part of the receiver is confirmed by a public document; the scrambler's start state is a setting for that reason.

## Tuning: notes

are in `crates/stacks/sdrkit-stack-hfdata/data/hf_band_presets.csv`, for the host to offer.
