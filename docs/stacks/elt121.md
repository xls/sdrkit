# ELT 121.5 MHz

Detects the swept tone of an analogue emergency locator transmitter on 121.5 MHz. Detection only: the beacon sends no identity.

Stack id: `elt121`. Group: Navigation.

## Tuning

| Property | Value |
|---|---|
| Default frequency | 121.5 MHz |
| Tuning range | 121 MHz to 122 MHz |
| Sample rate | 2 MHz |
| Smallest sample rate | 250 kHz |
| Signal bandwidth | 12 kHz |
| Offset from the signal | 20 kHz |
| Radio filter | 1.75 MHz |
| Automatic gain | Radio AGC |
