# MPT1327 trunking

MPT 1327 control channels: calls, acknowledgements and broadcasts, the system identity and the channel table.

Stack id: `mpt1327`. Group: Trunking.

Signal types: MPT 1327.

## Tuning

| Property | Value |
|---|---|
| Default frequency | 170 MHz |
| Tuning range | 30 MHz to 520 MHz |
| Sample rate | 240 kHz |
| Smallest sample rate | 48 kHz |
| Signal bandwidth | 12.5 kHz |
| Offset from the signal | 50 kHz |
| Automatic gain | Radio AGC |

## Settings

Give a value as `key=value` after the stack name. `sdrkit settings kind:stack:mpt1327` prints this table with every option.

| Key | Label | Kind | Default | Range or options | Help |
|---|---|---|---|---|---|
| `framing` | Framing | choice | `auto` | `standard` (Standard sync word), `tolerant` (Ignore sync word (French networks)), `auto` (Automatic) | How codewords are found: by the standard SYNC word, by their check bits alone (networks with another sync word), or automatically. |
| `control_channel` | Control channel number | whole number | -1 | -1 to 1023 | The control channel's own number, for the frequency column (-1: the first channel announced as a control channel). |

| `follow` | Follow calls | yes or no | false |  | Ask the radio to listen to the voice channel of each call. |
| `follow_groups` | Follow groups | text | empty |  | Talkgroups to follow ("1201 2000-2099"). Empty follows every call. A bad item is refused. |
| `follow_max_s` | Longest follow | duration (s) | 120 s | 5 to 1800 | A call followed longer than this ends (a stuck carrier). |
